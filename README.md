# Supplier, Product & Purchase Management System

This is a Laravel-based web application for managing suppliers,
products and purchase orders.

## Features

- Login system
- Supplier management
- Product management
- Purchase order management
- Purchase order details
- Print purchase order
- Search and filter
- Excel/CSV export

## Technologies

- Laravel 13
- PHP 8.4
- SQLite
- Bootstrap 5
- JavaScript
- DataTables
- Vite
